# BeatShuffle — Product Site

Static product page for **BeatShuffle** (iOS). No build step.

## Files
- `index.html` — product/landing page (EN/JP)
- `privacy.html` — privacy policy (EN/JP)
- `assets/` — icon & screenshots
- `.nojekyll` — serve files as-is on GitHub Pages

## Deploy (GitHub Pages)
Copy the **contents of this folder** to the root of the `BeatShuffle` repo
(the one published at https://hideto0926.github.io/BeatShuffle/), commit & push.

- Home: https://hideto0926.github.io/BeatShuffle/
- Privacy: https://hideto0926.github.io/BeatShuffle/privacy.html

> The product page is now the homepage. The privacy policy moved to
> `privacy.html`, so update the Privacy Policy URL in App Store Connect to
> `https://hideto0926.github.io/BeatShuffle/privacy.html`.
